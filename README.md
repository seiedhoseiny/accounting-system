# سیستم حسابداری دولتی توزیع‌شده

نرم‌افزار حسابداری دولتی برای وزارت بهداشت و واحدهای زیرمجموعه.
هر واحد سطح ۱ به‌صورت مستقل نصب می‌کند و اسناد نهایی‌شده به مرکز تجمیع می‌شوند.

## وضعیت پروژه
- فاز: ۰ (پایه‌ریزی)
- پیشرفت: مستندات معماری و ۷ ADR تثبیت شد
- قدم بعدی: ساخت اسکلت solution

## استک فنی
- Backend: ASP.NET Web Forms (.NET Framework 4.8)
- Database: SQL Server
- Data Access: EF6 + Dapper
- Sync: Windows Service + HTTPS/JSON
- Central: ASP.NET Web API (OWIN)
