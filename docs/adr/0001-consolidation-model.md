# ADR-0001: تجمیع اسناد نهایی‌شده از ۱۰۰ واحد سطح ۱ به مرکز

## وضعیت
پذیرفته‌شده — 2026-11-21

## زمینه
- ۱۰۰ واحد سطح ۱، هر کدام DB و سرور مستقل
- واحدهای سطح ۲ در همان DB واحد سطح ۱ ثبت می‌کنند
- تجمیع: اسناد حسابداری، رسیدها، حواله‌ها
- فقط اسناد نهایی‌شده (عبور از رسیدگی + اختصاص شماره) تجمیع می‌شوند
- مرکز فعلاً فقط گزارش می‌گیرد

## تصمیم
1. هر واحد سطح ۱ یک صف ارسال محلی دارد (`SyncQueue`).
2. هنگام نهایی‌سازی سند، رکورد در صف درج می‌شود.
3. سرویس پس‌زمینه (Windows Service) در بازه‌های کوتاه صف را به API مرکز push می‌کند.
4. Idempotency: هر سند `GlobalId` (GUID) دارد؛ مرکز ارسال تکراری را رد می‌کند.
5. فقط اسناد نهایی در صف قرار می‌گیرند.

## پیامدها
+ سادگی: فقط ۱۰۰ گره، بدون سلسله‌مراتب
+ کیفیت داده: فقط اسناد معتبر تجمیع می‌شوند
+ مقاوم به قطعی شبکه: صف محلی
- نیاز به سرویس پس‌زمینه در هر واحد
