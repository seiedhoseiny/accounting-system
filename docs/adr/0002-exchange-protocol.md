# ADR-0002: پروتکل تجمیع

## وضعیت
پذیرفته‌شده — 2026-11-21

## تصمیم
- API مرکزی جداگانه (ASP.NET Web API با OWIN) در همان solution
- JSON over HTTPS
- احراز هویت: API Key per unit (قابل ابطال از مرکز)
- Batch endpoint: هر درخواست حاوی آرایه‌ای از اسناد (مثلاً ۵۰ سند)
- پاسخ: برای هر سند `Accepted / Rejected(reason)`

## چرا API جداگانه و نه ASMX؟
- تست‌پذیر با Postman/curl
- JSON سبک‌تر از SOAP
- مستقل از UI، قابل استفاده‌ی مجدد
- در همان solution، بدون پیچیدگی اضافی

## پیامدها
+ جداسازی نگرانی
+ لاگ و مانیتورینگ متمرکز
- یک پروژه‌ی بیشتر برای نگهداری
