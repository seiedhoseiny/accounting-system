# واژه‌نامه

| اصطلاح | تعریف |
|--------|-------|
| واحد سطح ۱ | واحد اصلی با دیتابیس و سرور مستقل (مثلاً دانشگاه) |
| واحد سطح ۲ | زیرمجموعه‌ی واحد سطح ۱، بدون دیتابیس مستقل |
| سند افتتاحیه | اولین سند هر سال مالی (شماره ۱) |
| سند نهایی | سندی که از رسیدگی عبور کرده و شماره گرفته |
| سند اصلاحی | سندی که اثر سند اصلی را خنثی می‌کند |
| GlobalId | شناسه یکتای سند در کل سیستم (GUID) |
| UnitCode | کد یکتای هر واحد سطح ۱ (مثلاً کد دانشگاه) |
| SyncQueue | صف محلی اسناد آماده‌ی ارسال به مرکز |
| SchemaVersion | نسخه‌ی اسکیمای تبادل داده |
| FiscalYear | سال مالی (مثلاً ۱۴۰۵) |
